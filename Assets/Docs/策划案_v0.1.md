## 1. 玩法介绍

**在一个"命运序列"上排布手牌，绕开或借力敌方位置，用顺序杀死它们。**

玩家每回合把手牌填入一条横置的序列，敌方牌被随机插在序列里。结算按从左到右进行。不同位置决定不同的结算信息。顺序就是唯一的、也是全部的决策。

### 术语解释

| 术语 | 含义 |
|---|---|
|<b>关内概念|
|卡牌 | 我方可用资源或敌方攻击模式, 是游戏内行动的基本单位 |
| 命运序列 | 单个回合的结算轨道，每一小局长度固定 |
| 序列位 | 序列中的格子,允许向未被占据序列位中填充卡牌 |
| 虚无位 | 结算阶段未填牌的序列位，无效果，视为我方敌方空过一次行动 |
| 正逆位 | 牌的两种状态，效果不同 |
| 正逆位效果 | 牌在结算阶段的效果 |
| 翻转 | 切换牌的正逆位状态 |
| 回合翻转 | 本回合翻转,回合结束后翻转失效 |
| 关卡翻转 | 本关卡翻转,关卡结束后翻转失效 |
| 永久翻转 | 本局游戏中永久翻转 |
| 翻转计数 m | 本局累计的关卡翻转与永久翻转次数，回合翻转不计入 |
| 敌方顺序 | 多个敌方卡牌的相对位置信息 |
| 锁定目标 | 当前对敌方的行动时指定的敌方目标 |
|<b>属性|
| 生命值 | 我方或敌方的生命值, 直接相关游戏的胜负条件 |
| 护盾 | 抵挡伤害的临时值，回合结束清空 |
| 治疗 | 回复生命值, 不可超过生命上限 |

### 游戏流程

- 玩家携带初始牌组进入第一层，游戏正式开始
- 每层由若干关卡组成，全部通过视为本层通过。
- 关卡内任意时刻玩家血量归零视为死亡。敌方全部被打败视为胜利。
- 单个回合:
  - 初始阶段
    - 抽取4张新牌（首回合抽取6张），未打出的手牌保留
    - 随机敌方的序列位置
  - 决策阶段
    - 玩家确定手牌位置顺序
    - 决策是否要选择抗逆
    - 点击“开始结算”按钮，结束决策阶段
  - 结算阶段
    - 依据序列顺序执行卡牌效果
    - 若仍有敌方存活，重复进行决策和结算阶段
- 关卡结束:
  - 敌方被全部击杀后，玩家可选择其中一张加入牌库

### 牌库
- 初始
  - 每局开始时,玩家被随机分发16张小阿卡纳牌和一张大阿卡纳牌。
- 添加与删除
  - 在每一关卡结束后,玩家可在本关卡出现的敌人中选择一张将其加入牌库,或放弃这次选择,永久删除一张现有手牌

### 局
- 每次完整游玩以一局为一个单位
- 局内可分为很多层,所有层胜利后全局胜利
- 每局开始时进行一次初始牌库的抽取

### 层
- 每一层固定有三局小关卡和一局大关卡。
- 小关卡是以小阿卡纳牌为核心的关卡，每局有五名敌人，从不在玩家手中的其他小阿卡纳牌库中抽取。
- 大关卡是以大阿卡纳牌为核心的关卡，每局有三名敌人，从不在玩家手中的其他大阿卡纳牌库中抽取。
- 当前层通过后玩家进入下一层或结束游戏。

### 关卡
- 关卡是层的组成单位
- 每一关卡初始有固定的敌人生成
- 关卡中通过每一回合进行对战
- 关卡胜利后提供一次奖励,玩家可在本关卡出现的敌人中选择一张将其加入牌库,或放弃这次选择,永久删除一张现有手牌

### 回合
- 是玩家体验的最基本单位
- 每回合分为三个阶段
  - 初始阶段
    - 抽取4张新牌。若为第一回合则抽取6张
    - 未打出的手牌保留，不弃置
    - 随机敌方的序列位置
  - 决策阶段
    - 玩家确定手牌位置序列顺序
    - 决策是否要选择抗逆
    - 点击“开始结算”按钮，结束决策阶段
  - 结算阶段
    - 依据序列顺序执行卡牌效果
    - 清除回合翻转效果
- 若单个回合结束仍有敌方存活,进入新回合

### 序列
- 序列长度为6+敌方人数，其中 6 个是我方位。
- 敌人每回合重新随机插入，位置在玩家进行填充前公开可见。
- 玩家只能往空位放牌，不能覆盖敌人。
- 未填满的我方位留空，结算时视为虚无。

### 抗逆
- 每回合限一次，只能在决策阶段使用
- 弃置一张手牌,使我方一张手牌关卡翻转，或使敌方所有牌同时永久翻转
- 抗逆造成的手牌关卡翻转计入该牌的 m；敌方永久翻转计入对应敌人的 m

### 牌堆
取牌堆,手牌和弃牌堆。
关卡与关卡之间的牌堆相互独立：上一关的手牌、弃牌堆和牌序不带入下一关。
- 取牌堆
  - 关卡开始时初始化，将牌库所有牌打乱
  - 回合进行时，玩家的新牌从取牌堆抽取
- 手牌
  - 玩家当前回合可见，可操作的牌
  - 未打出的手牌在回合结束后保留，不进入弃牌堆
  - 只有手牌可作为序列的填充
- 弃牌堆
  - 回合结束时，在序列中的我方牌进入弃牌堆
  - 当取牌堆耗尽时，将弃牌堆重新洗好作为新的取牌堆，弃牌堆清空

### 序列结算规则

逐格从左到右，一格结算完再下一格。

| 卡牌类型 | 结算行为 |
|---|---|
| 我方攻击牌 | 命中当前的锁定目标 |
| 我方防御 / 治疗牌 | 立即作用于玩家（护盾、生命） |
| 我方增益牌 | 立即生效，持续本回合 |
| 敌方牌 | 进行攻击，执行其正位或逆位效果 |
| 死亡敌人 | 回合开始序列初始化时跳过，本关卡不再有影响 |

### 锁定目标

- 攻击牌或其他以敌方单个单位为目标的牌的目标
- 回合开始时自动确定为当前顺序下的最左侧存活敌人
- 最左侧敌人死亡后，锁定目标自动改为当前最左侧的存活敌人

### 正逆位系统

- 牌具有正逆位状态，不同正逆位效果不同
- 翻转是对正逆位改变过程的描述
  - 回合翻转：本回合翻转,回合结束后翻转失效
  - 关卡翻转: 本关卡翻转,关卡结束后翻转失效
  - 永久翻转: 本局游戏中永久翻转，事实上直接改变了本张牌的正逆位状态字段
- 翻转可叠加：如一张牌同时有回合翻转和关卡翻转，那么其实际上会发挥不翻转的效果
- 翻转计数 m：本局累计的关卡翻转与永久翻转次数，回合翻转不计入；m 跨关卡保留，直到本局结束
- 抗逆：玩家游戏过程中的主动翻转行为
  - 每回合可执行一次：所有存活的敌人同时永久翻转或一张手牌关卡翻转。
  - 代价：弃 1 张手牌。

### 死亡与胜负

- 敌人生命归零 -> 死亡，退出序列，其位变为虚无
- 敌人全部死亡 -> 关卡胜利
- 所有层的所有关卡均已通关 -> 本局胜利
- 玩家生命 ≤ 0 -> 失败

### 属性
- 生命值
  - 玩家具有120点初始生命值
  - 玩家生命值跨关卡保留，不自动回满
  - 小阿卡纳牌作为敌方时具有20点生命值
  - 大阿卡纳牌作为敌方时具有60点生命值
- 护盾
  - 护盾存在时，可代替玩家或敌人受到伤害
  - 护盾被击破溢出伤害依旧结算血量
  - 护盾每回合结束后清除

### 行为
- 治疗
  - 回复生命值。不可超过血量上限
- 攻击
  - 削减生命值
- 强化
  - 对治疗和攻击进行强化，最终值向下取整
  - 伤害 = 基础伤害 * 强化倍率
  - 治疗 = 基础治疗 * 强化倍率

## 3. UI与交互

### 开始界面
- 标题
- 开始游戏按键
- 设置按键
- 退出游戏按键

### 设置界面
- 音量调整
- 屏幕分辨率
- 全屏开关

### 单层界面
- 关卡与关卡中间的当前层界面
- 层中的节点代表关卡，可选择下一关卡

### 关卡界面
- 中上方：命运序列横向铺开，需要对敌方牌和我方做区分。
- 下方：手牌展开。
- 每个敌方格：血条悬浮在牌上方。
- 底部：我方血量与护盾值。
- 左下角：取牌堆和弃牌堆牌的数量
- 右下角：弃牌区域
- 底部中央：开始结算按钮
- 左上角：停止菜单按键

#### 关键交互
- 开始结算：点击“开始结算”按钮结束决策阶段，未填充的序列位保持虚无。
- 拖拽：鼠标长按点击一张卡牌可实现拖拽。
- 落点：拖入序列位，手牌区或弃牌区，分别执行落在序列位，落回手牌区和销毁
- 抗逆：卡牌进入弃牌区销毁后，进入特殊状态，玩家双击敌方任意牌对敌方全体翻转；双击我方牌时对其进行翻转。
- 悬停在某张牌上0.3s以上，显示其名称，正逆位状态和正逆位效果
- 结算播放：逐格动画


## 4. 优化方向

- 已完成设计的卡牌效果是否合适?
- 只有生命,护盾,回复是否机制较少,需求更多的机制提高策略?
- UI交互逻辑是否合理?
- UI即不同塔罗牌的美术风格?
