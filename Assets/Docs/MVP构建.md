# MVP 构建说明

## 1. 目标

用最小成本验证核心循环是否成立：

**主菜单 → 第一层界面 → 小关卡 → 大关卡 → 本局结束**

本期不追求美术、数值平衡和内容量。重点是跑通：抽牌、序列放置、开始结算、逐格结算、正逆位、抗逆，以及能支撑后续扩展的卡牌与关卡数据结构。

## 2. 本期范围

### 做

- 主菜单点击“开始游戏”直接进入第一层界面。
- 一层 = 3 个小关卡 + 1 个大关卡；节点按顺序解锁，只有当前可打的节点可点击。
- 每场战斗固定 3 个敌人。
- 战斗流程：抽牌 → 放置/撤回 → 抗逆 → 开始结算 → 逐格结算 → 下一回合/胜负。
- 暂停菜单保留；点击“返回主菜单”直接结束当前局并弃置进度。
- 打完大关卡后本局直接结束；玩家死亡同样结束本局，均返回主菜单。
- 卡牌、敌人、关卡使用固定配置并数据化，代码结构为后续多层、更多卡牌留出扩展空间。

### 不做

- 层地图美术、关卡分支、商店、事件。
- 关卡奖励选牌/删牌。
- 继续游戏、存档、读档。
- 多层、跨层成长。
- 卡牌插画、动画（只保留必要的淡入淡出、逐格高亮/停顿）。
- 音效、音乐。
- 数值平衡。

## 3. 牌池

只使用策划案中已完成效果的牌：

- 小阿卡纳：权杖 I~X、宝剑 I~X、圣杯 I~X，共 30 张。
- 大阿卡纳：愚者、魔术师、力量、命运之轮、倒吊人，共 5 张。

星币、各花色的侍从/骑士/王后/国王、其余大阿卡纳本期不进入牌池。卡牌数据结构要能容纳它们，后续补充效果即可接入，不需要改动整体结构。

初始牌组固定 17 张（16 张小阿卡纳 + 1 张大阿卡纳），全部从上述牌池中选取，具体牌表在实现前确定。

## 4. 规则落地

### 回合

- 初始阶段：抽取 4 张新牌，首回合抽取 6 张；未打出的手牌保留。
- 敌人随机插入序列，插入后位置公开。
- 决策阶段：拖拽手牌到空序列位；拖拽已放置的牌回手牌区可撤回；拖拽手牌到右下弃牌区可弃置。
- 点击“开始结算”按钮进入结算阶段；未填充的序列位保持虚无。
- 结算阶段：从左到右逐格结算；单格结算后停顿 0.2~0.3 秒并高亮，同时输出日志。
- 回合结束仍有敌人存活则进入下一回合。

### 牌库 / 手牌 / 弃牌堆

- 每关开始时，手牌、弃牌堆清空，所有牌回到取牌堆并洗牌。
- 关卡与关卡之间的牌堆相互独立：上一关的手牌、弃牌堆和牌序不带入下一关。
- 回合开始从取牌堆抽牌；取牌堆不足时，将弃牌堆洗回取牌堆后再抽。
- 回合结束时，序列中的我方牌进入弃牌堆；未打出的手牌保留。
- 手牌上限本期不做限制。

### 序列

- 长度 = 6 + 敌人数；本期 3 个敌人，固定 9 格。
- 6 个我方位 + 3 个敌方位。
- 敌人位不能放牌；空格在结算时视为虚无。

### 目标

- 锁定目标 = 当前最左侧存活敌人。
- 最左侧敌人死亡后，后续攻击自动改为新的最左侧存活敌人。

### 敌人

- 每场战斗固定 3 个敌人，配置固定。本期所有关卡都按 3 个敌人；策划案中小关卡的 5 个敌人留到后续。
- 小阿卡纳敌人：只结算伤害（数值 n）和血量（20），不执行花色效果。
- 大阿卡纳敌人：血量 60，按策划案结算伤害与正逆位特殊效果（愚者、魔术师、力量、命运之轮、倒吊人）。
- 敌人不抽牌、不使用牌库。

### 抗逆

- 每回合限一次，只能在决策阶段使用。
- 将 1 张手牌拖入弃牌区作为代价，弃置的牌进入弃牌堆，并进入抗逆选择状态。
- 校验：至少存在一个合法目标（存活敌人，或另一张手牌）；不满足则退回手牌。
- 二选一：
  - 敌方全体存活单位永久翻转；
  - 我方 1 张手牌关卡翻转。
- 抗逆产生的关卡/永久翻转计入 `m`；回合翻转不计入。
- 目标选择使用双击；弃牌后不可取消或撤回。

### 正逆位

- 牌的当前正逆位状态必须可见。
- 回合翻转：回合结束清除。
- 关卡翻转：关卡结束清除。
- 永久翻转：保留到本局结束，直接修改牌的状态。
- 翻转可叠加，叠加两次视为抵消。

### 生命 / 护盾 / 治疗 / 强化

- 玩家初始生命 120；生命值跨关卡保留，不自动回满。
- 护盾先于生命扣除，溢出伤害继续扣血；回合结束清空。
- 治疗不超过生命上限。
- 强化只影响伤害/治疗，最终值向下取整。

### 胜负

- 玩家生命 ≤ 0：本局失败，返回主菜单。
- 当前关卡敌人全部死亡：关卡胜利，回到层界面，解锁下一节点。
- 大关卡胜利：本局胜利，返回主菜单。

## 5. UI 最小形态

- 层界面：4 个关卡节点（3 小 + 1 大）纵向或横向排列；已通关、当前可打、未解锁三种状态；点击当前节点进入战斗。
- 战斗界面：
  - 上方：命运序列（9 格），敌我颜色区分。
  - 下方：手牌。
  - 敌人牌上方：血条。
  - 底部：玩家生命/护盾。
  - 左下：取牌堆/弃牌堆数量。
  - 底部：开始结算按钮、抗逆按钮。
  - 左上：暂停按钮。
- 暂停：继续、设置、返回主菜单。
- 所有牌面和按钮文本使用英文，中文等字体方案确定后再替换。
- 卡牌只用几何底板 + 名称 + 效果文字；正逆位用旋转 180° 或明显标签区分。
- 保留一个简单的结算日志区域，显示最近几条结算记录。

## 6. 技术约束

- 现有主菜单、设置菜单沿用；先修复 Build Settings、场景名、GameManager 关卡表，保证 Menu → 层 → 战斗 → 返回 能跑通。
- 卡牌用数据配置；效果通过可扩展的效果定义接入，避免一牌一类的硬编码。
- 敌人、关卡配置数据化；战斗场景复用，关卡差异由数据决定，为多层留扩展点。
- 文本统一走一个入口，方便以后替换中文字体。

## 7. 开发期工具（不计入验收）

- 固定随机种子。
- 跳过关卡。
- 指定手牌。
- 一键击杀敌人。
- 结算日志。

## 8. 验收标准

1. 主菜单点击开始游戏，能进入层界面。
2. 层界面 4 个节点状态正确，能依次打完 3 小关 + 1 大关。
3. 每场战斗固定 3 个敌人，序列固定 9 格。
4. 首回合抽 6、之后每回合抽 4，未打出的手牌保留；牌库抽空能洗回弃牌堆。
5. 手牌能拖入空位、拖回手牌区撤回、拖入弃牌区弃置；未填位显示虚无。
6. 点击开始结算后逐格结算，伤害/治疗/护盾/死亡/目标重定向/大阿卡纳特殊效果正确。
7. 通过拖牌到弃牌区触发抗逆，每回合一次；两种模式与双击目标正确；`m` 只受关卡/永久翻转影响。
8. 暂停返回主菜单会弃置本局；小关胜利回到层界面，大关胜利和玩家死亡回到主菜单。
9. 全程无报错、无软锁；英文文本显示正常。
