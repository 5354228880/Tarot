# 卡牌效果表（MVP）

> 配套：`策划案_v0.1.md`（规则）、`MVP构建.md`（范围）、`技术设计.md`（架构）。
> 本表是数据实现清单；本期只实现下列 35 张牌。

## 1. 约定

- `n`：小阿卡纳点数 1~10；宫廷牌本期不实现。
- `m`：本局累计的关卡翻转与永久翻转次数；回合翻转不计入。跨关卡保留，直到本局结束。
- 百分比、除法结果向下取整。
- 目标：
  - `LockedEnemy`：当前最左侧存活敌人，死亡后自动重定向。
  - `Self`：牌的所有者。
  - `Adjacent`：物理相邻的序列位，空位跳过。
  - `SequenceEnds`：序列中第一张和最后一张非空牌。
  - `AllEnemies`：所有存活敌人。
  - `HandCard`：手牌。
  - `NextCard`：按当前结算方向的下一个非空序列位。
- 大阿卡纳的 15 点伤害已写进效果列表；力量覆盖为 20/25，不再额外叠加基础伤害。
- 表中的 `Damage` 是唯一伤害来源，不存在额外的 `BaseDamage` 叠加。
- 敌方小阿卡纳只结算 `n` 伤害、20 血，不执行花色效果。
- 敌方大阿卡纳 60 血，按本表结算伤害与特殊效果。
- 玩家 120 血。

## 2. 效果原语

| 原语 | 参数 | 说明 |
|---|---|---|
| `Damage` | amount, target=LockedEnemy | 受强化修正，先扣护盾再扣血 |
| `Heal` | amount, target=Self | 不超过生命上限 |
| `Shield` | amount, target=Self | 叠加，回合结束清空 |
| `BuffNext` | kind(Damage/Heal), percent | 加到下一张牌的对应效果，可叠加，下一张牌结算完消耗 |
| `Flip` | type(Turn/Level/Permanent), target | 切换正逆位；关卡/永久翻转使该牌 `m+1`，回合翻转不计入 |
| `SkipResolve` | scope=SequenceEnds | 本回合首尾牌不结算 |
| `RepeatNext` | times | 下一张牌结算多次，单张牌每回合最多 4 次 |
| `Transform` | target, pool, duration=Turn | 临时替换牌面，保留原牌的翻转状态与 `m` |
| `SetDirection` | mode | Forward / Backward / ForwardAndBackward / PlayerChoice / Random |
| `PlacementRule` | rule | 敌人插入规则：NoEnds / NextIsEnemy |
| `SelfDamage` | amount | 攻击后扣自己的血，可致死 |
| `Draw` | count | 预留，本期卡池未使用 |

## 6. 翻转、目标与结算细则

### 正逆位

- 有效朝向：`BaseReversed XOR TurnFlip XOR LevelFlip`。
- 永久翻转直接切换 `BaseReversed`，保留到本局结束。
- 回合翻转在回合结束清除；关卡翻转在关卡结束清除。
- 翻转可叠加，叠加两次抵消；每次关卡翻转/永久翻转使 `m+1`，回合翻转不计入。
- 倒吊人的翻转是回合翻转，不会增加 `m`；抗逆的手牌关卡翻转会增加 `m`。

### 抗逆

- 每回合一次，仅决策阶段。
- 将 1 张手牌拖入弃牌区，进入抗逆选择状态；弃牌后不可取消。
- 二选一：所有存活敌人永久翻转；或 1 张手牌关卡翻转，目标用双击选择。
- 抗逆造成的手牌关卡翻转会计入该牌 `m`；敌方永久翻转会计入对应敌人的 `m`。
- 敌方小阿卡纳被翻转不改变伤害，只有大阿卡纳会受影响。

### 结算

- 先收集全局修正（愚者跳过首尾、命运之轮方向），再逐格结算。
- 每张牌的效果按列表顺序执行；每步之后检查死亡与重定向。
- 玩家生命 ≤ 0 立即失败；敌人全灭在回合结束后判胜。
- 护盾先于生命扣除，溢出继续扣血；回合结束清空。
- 强化：`floor(基础值 × (1 + 百分比合计))`。
- `BuffNext` 在下一张牌结算完消耗；即使下一张没有对应类型的伤害/治疗，也消耗。
- `RepeatNext` 与命运之轮同时存在时，单张牌最多结算 4 次（命运之轮 2 × 愚者 2）。
- 愚者自身若在首尾，仍会被跳过，但它提供的全局修正先生效。
- 魔术师变换持续到回合结束；打出的变换牌进入弃牌堆时恢复原牌；没有合法目标或手牌不足时按可用数量变换，没有则跳过；变换后按新牌面的伤害、效果与放置规则结算，血量上限不变。
- 愚者的敌方放置规则无法满足时重试，仍失败则忽略该约束。

## 8. 新增一张牌

1. 在卡牌数据里新增定义：Id、Arcana、Suit、Rank、正逆位效果列表。
2. 优先复用已有原语；确实需要新原语时，先加 Core 实现和单测，再补本表。
3. 加入本期牌池或关卡配置。
4. 在本表补一行，并补对应单测。
5. 跑一次数据校验，确认没有空效果或未实现标记误入牌池。
